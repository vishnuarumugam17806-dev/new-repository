# DB VITHRA — User Manual

Welcome to the **DB VITHRA** User Manual! This guide helps you navigate and operate the platform to design and manage databases efficiently.

---

## 1. Getting Started

1. **Accessing the App:** Start the server by running `python app.py` and open your web browser to `http://localhost:5000`.
2. **Account Registration:** Click on the **Register** link in the navbar, enter a username, email, and password to create your account.
3. **Logging In:** Go to **Login**, enter your credentials, and access your profile.

---

## 2. Generating Databases with AI

1. Go to the **AI Generator** tab.
2. Enter your **Project Name** (e.g. "Hospital System").
3. In the **Requirements** box, describe your database using natural language:
   > *Example: "I need a school system where students attend classes taught by teachers, grades are tracked, and courses belong to departments."*
4. Select your target database dialect (SQLite, PostgreSQL, MySQL, or MS SQL Server).
5. Click **Generate Schema**.
6. The AI engine will extract entities, define attributes, normalise the tables (3NF), build foreign key relationships, and prepare code.

---

## 3. Exploring the Output Tabs

Once generated, you are redirected to the **Schema Details** screen:

* **SQL Script:** View the raw `CREATE TABLE` script with constraints, primary keys, and foreign keys.
* **ER Diagram:** Interactive Mermaid.js diagram representing relationships (1-to-many, etc.). You can zoom, pan, and review linkages.
* **Data Dictionary:** A detailed documentation table showing every column's type, purpose, and constraints.
* **Sample Data:** Auto-generated `INSERT` statements to quickly populate your database with mock data.
* **NoSQL Document Schema:** Equivalent MongoDB structures corresponding to the relational model.
* **REST API Docs:** Autogenerated list of CRUD endpoints for building a backend service.
* **Suggestions:** Recommendations for columns indexing, data types, and normalisation tweaks.

---

## 4. Downloading and Deploying

### Download SQL
* Click **Download SQL** on the details page to save the script to your computer.

### Live Deployment
* Go to the **Deploy** section.
* Select a target database type:
  * **SQLite:** Auto-builds a physical database file on the server and provides a download link.
  * **MySQL / PostgreSQL / MSSQL:** Enter database credentials, host, and port. The application will log in, run the script, create the database, and verify the tables.

### Push to SSMS (SQL Server Management Studio)
* Navigate to the **Push to SSMS** page.
* Input server parameters, select authentication (Windows or SQL Server Auth), and submit. The platform deploys the schema to your SQL Server instance immediately.
